# White Glove

Tag in the neighbourhood: litterbugs drop paper on the street, your team catches them and cleans up. The cleanest team wins.

Godot 4.7.2 (GDScript), deterministic integer simulation, online play with friends through a relay with rollback.
Work in progress: the shared base is in place; the clean-up game itself comes in phase 2.
